# SECTOR 7

Сюжетный FPS на Three.js и Electron. В кампании доступны две миссии: заброшенный бункер и исследовательский комплекс. По мере прохождения открываются новые задания, а результаты и прогресс сохраняются локально.

**Технологии:** Three.js, Electron, процедурные PBR-материалы, динамическое освещение, тени, Bloom и постобработка.

**Управление:** WASD — движение, Shift — бег, мышь — обзор и прицеливание, ЛКМ — огонь, R — перезарядка, F — фонарь, F2 — настройки графики, F3 — монитор производительности, F11 — полный экран.

## Скачать

В разделе **[Releases](https://github.com/Yokushiro/sector7-fps/releases)** доступны две Windows-версии:

- `SECTOR7-…-portable.exe` — портативная версия, не требует установки.
- `SECTOR7-…-setup.exe` — установщик с возможностью выбрать папку установки.

## Локальный запуск

Для запуска проекта из исходного кода потребуется установленный Node.js.

```bash
npm ci
npm start
```

Для проверки модулей и тестов:

```bash
npm test
```

## Сборка для Windows

Для сборки Windows-версий используется Electron Builder.

```bash
npm run dist
```

Готовые файлы появятся в папке `dist`.
