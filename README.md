# SECTOR 7

Сюжетный FPS на Three.js и Electron. В кампании четыре связанные миссии: заброшенный бункер, исследовательская лаборатория, реакторное ядро и открытая поверхность комплекса. Каждая локация включает боевую зону и физически проходимые сервисные коридоры; в лаборатории после зачистки необходимо отключить внешний контур на центральной панели, в реакторе вручную запустить аварийное отключение, а на поверхности уничтожить преследование, активировать эвакуационный маяк и добраться до посадочной площадки. Следующий сектор заранее собирается в скрытой группе сцены: при пересечении открытого шлюза геометрия уже готова. Короткое затемнение скрывает передачу управления, здоровье и боезапас сохраняются, вступительные реплики следующей миссии звучат по радио без остановки движения, а музыка продолжается с плавной сменой акустики. История раскрывается через вступительные и финальные диалоги, а в реакторе необходимо выбраться по коридору за 90 секунд, а финальная эвакуация с поверхности ограничена 120 секундами. Прогресс и статистика сохраняются локально.

**Технологии:** Three.js, Electron, процедурные PBR-материалы, динамическое освещение, тени, Bloom, постобработка и процедурное звуковое окружение.

**Управление:** WASD — движение, Shift — бег, мышь — обзор и прицеливание, ЛКМ — огонь, R — перезарядка, E — взаимодействие с терминалами и диалогами, F — фонарь, F2 — настройки графики, F3 — монитор производительности, F11 — полный экран.

## Скачать

В разделе **[Releases](https://github.com/Yokushiro/sector7-fps/releases)** доступны две Windows-версии:

- `SECTOR7-…-portable.exe` — портативная версия, не требует установки.
- `SECTOR7-…-setup.exe` — установщик с возможностью выбрать папку установки.

## Локальный запуск

Для запуска проекта из исходного кода потребуется установленный Node.js.

```bash
npm ci
npm start
```

Для проверки модулей и тестов:

```bash
npm test
```

## Сборка для Windows

Для сборки Windows-версий используется Electron Builder.

```bash
npm run dist
```

Готовые файлы появятся в папке `dist`.
