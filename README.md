# SECTOR 7

**Версия 1.2.0** · сюжетный FPS на Three.js и Electron.

В версии 1.2.0 доступна кампания из шести связанных миссий: заброшенный бункер, исследовательская лаборатория, реакторное ядро, поверхность комплекса, архив памяти и передающий узел. Каждая локация включает боевую зону и физически проходимые сервисные коридоры; в лаборатории после зачистки необходимо отключить внешний контур на центральной панели, в реакторе вручную запустить аварийное отключение, на поверхности уничтожить преследование и активировать маяк, затем вернуться в архив памяти за исходным ключом и отключить главный передатчик на внешнем узле. Следующий сектор заранее собирается в скрытой группе сцены: при пересечении открытого шлюза геометрия уже готова. Короткое затемнение скрывает передачу управления, здоровье и боезапас сохраняются, вступительные реплики следующей миссии звучат по радио без остановки движения, а музыка продолжается с плавной сменой акустики. История раскрывается через вступительные и финальные диалоги, а в реакторе необходимо выбраться по коридору за 90 секунд, а финальная эвакуация с поверхности ограничена 120 секундами. Прогресс и статистика сохраняются локально.

**Технологии:** Three.js, Electron, процедурные PBR-материалы, динамическое освещение, тени, Bloom, постобработка и процедурное звуковое окружение.

**Управление:** WASD — движение, Shift — бег, мышь — обзор и прицеливание, ЛКМ — огонь, R — перезарядка, E — взаимодействие с терминалами и диалогами, F — фонарь, F2 — настройки графики, F3 — монитор производительности, F11 — полный экран.

## Что нового в 1.2.0

- Расширенная кампания из шести связанных миссий с сюжетными радиодиалогами и дополнительными записями.
- Два новых сектора: «Архив памяти» с серверными стойками и криокапсулами, «Передающий узел» с антенной и штормовыми эффектами.
- Продолжение сюжета после поверхности: возвращение в архив за ключом и финальное отключение передатчика.
- Открытая локация «Последний сигнал» с маяком и возвращением в комплекс.
- Босс «Сторож» с 280 HP и отдельной полосой здоровья.
- Пять архетипов противников, улучшенный AI, тактическое движение и обход укрытий.
- Сохранение прогресса, статистики, здоровья и боезапаса между секторами.
- Графические пресеты F2, монитор производительности F3, процедурная музыка и атмосферные профили.
- Исправлена ошибка аварийной сигнализации реактора, из-за которой игровой цикл падал при запуске эвакуации.

Полная история изменений — в [CHANGELOG.md](CHANGELOG.md).

## Скачать

В разделе **[Releases](https://github.com/Yokushiro/sector7-fps/releases)** доступны две Windows-версии:

- `SECTOR7-…-portable.exe` — портативная версия, не требует установки.
- `SECTOR7-…-setup.exe` — установщик с возможностью выбрать папку установки.

## Локальный запуск

Для запуска проекта из исходного кода потребуется установленный Node.js.

```bash
npm ci
npm start
```

Для проверки модулей и тестов:

```bash
npm test
```

## Сборка для Windows

Для сборки Windows-версий используется Electron Builder.

```bash
npm run dist
```

Готовые файлы появятся в папке `dist`.
