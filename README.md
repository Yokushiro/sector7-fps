# SECTOR 7

Сюжетный FPS на Three.js и Electron. В кампании три связанные миссии: заброшенный бункер, исследовательская лаборатория и реакторное ядро. Каждая локация включает боевую зону, физически проходимый коридор к следующему сектору и сюжетные терминалы. После выхода следующий уровень загружается прямо в текущую игровую сессию, без перезапуска приложения. История раскрывается через вступительные и финальные диалоги, а в заключительной миссии необходимо вручную активировать аварийное отключение реактора и эвакуироваться. Прогресс и статистика сохраняются локально.

**Технологии:** Three.js, Electron, процедурные PBR-материалы, динамическое освещение, тени, Bloom, постобработка и процедурное звуковое окружение.

**Управление:** WASD — движение, Shift — бег, мышь — обзор и прицеливание, ЛКМ — огонь, R — перезарядка, E — взаимодействие с терминалами и диалогами, F — фонарь, F2 — настройки графики, F3 — монитор производительности, F11 — полный экран.

## Скачать

В разделе **[Releases](https://github.com/Yokushiro/sector7-fps/releases)** доступны две Windows-версии:

- `SECTOR7-…-portable.exe` — портативная версия, не требует установки.
- `SECTOR7-…-setup.exe` — установщик с возможностью выбрать папку установки.

## Локальный запуск

Для запуска проекта из исходного кода потребуется установленный Node.js.

```bash
npm ci
npm start
```

Для проверки модулей и тестов:

```bash
npm test
```

## Сборка для Windows

Для сборки Windows-версий используется Electron Builder.

```bash
npm run dist
```

Готовые файлы появятся в папке `dist`.
